# 普通网页与小红书摄取交付验收

日期：2026-11-16。规格 #40，任务 #48、#49；实现 checkout 为现有 migration 工作区，分支 codex/wiki-ingestion-cli，基线 bb61807。这里分别记录合成测试、真实转换、正式入库及尚未接通的能力；真实链接、分享参数、原始正文、任务与会话 ID 仅保留于私有运行目录。

## 实现

- 普通网页正式接入统一 CLI；静态获取失败可用临时 Chrome 渲染。浏览器全部 GET 经公网验证和固定连接的 HTTPS 获取器，拒绝私网、混合 DNS、WebSocket、非 HTTPS 和非 GET。保留原始响应与渲染 DOM；标题层级、表格、代码与图片进入 Markdown。
- 小红书支持单笔记长链接和 xhslink.com / xhslink.cn 短链，保留私有访问参数。解析桌面或实测移动详情，严格校验目标 ID；预览/OG/预加载卡片不当全文。顺序图片、原始状态、本机 OCR 与完整正文分别保留。
- 短链部分获取时即保留已确认的规范身份，后续补料沿同一来源。更换分享参数追加历史，不覆盖初始分享文案，也不刷新恢复预算。
- 同一规范来源的并发发布互斥；缺图、未知图片格式、未转录视频/实况不进入正常知识编译。未知格式保留已下载字节。既有原件及人工知识保护流程继续使用。
- 两轮来源失败进入待补与真实 Codex 维护；聚合键剔除每任务路径，完整诊断留私有日志。已知未接入的社交平台不因通用网页支持而自动开发。

## 后续来源接入约定

先在独立任务中确定单条来源与真实验收样本。入口明确平台和稳定身份，获取地址保留必要参数；第二层输出带原始材料、article.md、附件映射和完整性状态的内容包。只有严格核实的规范 URL 才交给第一层保持映射。来源获取、媒体转录与 OCR 缺口必须准确返回，完整包再交给统一冻结、Wiki 编译、受保护发布及读回检索。完成公共行为测试和真实入库验收后再列为正式支持来源。

小红书知识模型曾两次输出中文概念路径，发布层拒绝，原件和正文已成功阶段保留；补充拒绝路径反馈后，同一任务正式发布。网页阅读结构曾被模型改变，受保护流程停下并保留已成功阅读单元；修复增强失败证据和反馈，并把标题/列表前缀与链接一样逐字保护；真实触发点是OCR英文句子以 `2024.` 起始，模型把它译为“2024年”而改变Markdown列表计数。语种先逐段判断，引用地址的字母不参与正文语种统计，中文段落原样保留；OCR图片标识保持元数据，只合并相邻英文自然语言段。语种识别仍是字符比例启发式。旧占位符映射的失败反馈按版本隔离，成功单元仍复用；英文碎片以稳定片段ID批量处理，验证完整且唯一的返回ID，每个原段落独立ID、独立结构校验与缓存，相同片段只翻译一次并回填全部位置；先复用升级前已验证的合并译稿；未缓存部分按原段落拆分，无效批次或片段仅补未完成部分。不替换原件，也不更换既定阅读模型。
