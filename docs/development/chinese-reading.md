# 中文阅读与 Agent 工具：开发验收

日期：2026-09-27。分支 `codex/wiki-v03`。本记录描述开发分支的实现，不表示已部署或已完成全部 0.3.0 任务。

## 已实现

- `wiki_record`：仅向指定 Wiki Agent、飞书账号、发送者和会话开放；以原消息 ID 读取并核验用户的收集命令。工具参数没有 Vault 路径、令牌或任意文件写入接口。
- `wiki_status`：只能读取当前发送者和会话的任务；显示实际阶段、结果和回执确认状态。
- 完成回执包含标题、摘要、来源位置、附件状态、中文阅读状态及待审编号。
- 新来源编译后生成 `reading/<英文名>.zh.md`，独立于来源卡；链接不可变英文原件。该目录不作为第二份来源再次编译。
- 译文逐次使用 Codex CLI `gpt-5.6-terra`；知识编译继续 `gpt-6-sol`。中文为主的片段直接保留，代码块保持原字节，链接与公式等用占位符保护。
- 以最多 4000 字符的片段处理，保存已通过结构检查的片段。翻译失败仍返回已完成的知识编译和明确 pending 状态。
- `wiki_retry_translation` 只续作未完成翻译；校验原件哈希，复用已完成片段，不重新采集、Flash 处理或编译。旧版归档不补译。
- 附件引用重写为可访问的归档路径，保留标题及引用式图片；代码示例内的路径不改写。

## 已完成验证

确定性合成样本验证：完整中文正文与摘要分开，保留代码及 URL，原件不变；图片可定位；丢段或破坏引用时不标为完成；额度失败后补译只处理未完成片段；已完成补译重复执行不调用模型。

真实模型验证：同一合成实验文章使用 `gpt-6-sol` 生成来源卡、实体和概念，再用 `gpt-5.6-terra` 生成全文中文阅读。抽样逐句核对，A 笔两天、B 笔三天、每类一支样本、不能推广成普遍规律四项全部保留。复现脚本为 `scripts/manual/chinese-reading.js`，仅使用隔离合成目录，结束后清理。

OpenClaw 工具契约及隔离插件加载检查通过；未重启实际 Gateway、未向飞书发送测试消息。
