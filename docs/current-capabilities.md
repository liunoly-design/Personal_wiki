## 接口边界

nashsu 0.6.11 的 HTTP API 不提供文章写入端点。已采用用户确认的方式：薄本机受保护写入层负责落盘，nashsu 原生 API 负责回读核验、搜索和后续阅读。自动提取保持关闭；迁移原始资料时须暂停文件监控并确认原生队列为空，避免删除事件触发关联页清理。

飞书入口支持 `小婕收集：内容`、`小婕重新收集：链接`，兼容 `小婕 wk 记录：链接`；`备注：` 或 `背景：` 另起一行区分个人说明；用户权限校验及普通完成回执保持原配置。迁移恢复旧任务设置为静默，未补发旧消息。

真实飞书新用户入站与配置回执由用户正常发送消息验收，本轮未发送测试消息。普通博客不使用私人登录会话；HTTPS 公网抓取有响应大小和重定向限制。
