## 接口边界

nashsu 0.6.11 的 HTTP API 不提供文章写入端点。已采用用户确认的方式：薄本机受保护写入层负责落盘，nashsu 原生 API 负责回读核验、搜索和后续阅读。关闭重复自动提取，文件监控仅负责刷新。

飞书命令仍为 `小婕 wk 记录：链接`；用户权限校验及普通完成回执保持原配置。迁移恢复旧任务设置为静默，未补发旧消息。
