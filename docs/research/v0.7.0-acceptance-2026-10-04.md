The repeated phrase “最后一句” was often recognized as “最后依据”; this contributes substitutions. Negation and discourse words were retained in checked synthetic responses. Repeated spoken text is retained; no text-only guess deletes repetitions. Silence segments are labeled and are not uploaded. These samples show the 5-minute setting is unsuitable for this backend; the implementation freezes **60 seconds**, 16kHz mono work WAV, pause-aware cuts and up to one-second overlap outside silence. Backend output does not provide word timestamps/confidence. No natural-speech human-reference CER, English/mixed-language quality, noise/overlap or arbitrary Chinese content completeness is claimed. Naturally spoken, explicitly licensed 10/20/30-minute full-reference quality acceptance remains outstanding.

The backend can silently omit content. Shorter chunks, continuous time coverage, empty-voiced/silence and low text-density/truncation checks reduce risks but cannot detect all omissions. The archive labels raw machine text as uncorrected; it is not a verified fact. Unknown cloud requests require an explicit new recovery command, may consume quota again, and never reset the five-call per-segment budget.

## Product and safety behavior

- Default compressed archive uses libx264 CRF28/preset medium, AAC128, faststart; short edge ≤720, no enlargement. Original mode uses the selected ≤1080 stream bytes without re-encoding. Source full audio is extracted before video compression; full decode and duration checks precede acceptance.
- Only supported public single-video URL/redirects and media CDN suffixes. Pinned public addresses/TLS at every redirect; no cookies. Narrow Google HTTPS DNS fallback only for the local 198.18/15 Fake-IP range; private/LAN targets remain rejected. No global network configuration changed.
- Stable platform ID plus frozen mode groups short/long aliases. Shared video lease prevents simultaneous publication. New mode gets a media version linked to the existing knowledge source, not another independent source. Formal pages/bytes remain immutable; manual changes are never replaced. Failed transcript leaves API-verified video/audio with explicit pending states, without claiming video knowledge.
- Stage results, raw CLI machine responses, input/config/output hashes, segment plan, provenance and cleanup log remain durable outside queue workspace. Successful segments and publication are reused after restart. Unknown results do not auto-replay. Five-call ASR budget survives process reentry, including explicit recovery.
- Long/large input requires existing exact fingerprint confirmation. Unknown-size download pauses at 1GB; no resolution bypass. Free-space budget includes download plus output/audio/chunks. Damaged media, no audio and non-saving compression remain failures.
- Formal binary media are written through the existing descriptor-based protected store and API-read media page. Same-filesystem work aliases share the archived inode to avoid duplicate binary storage; other filesystems retain verified copies. Cleanup uses a frozen source/chunk-only list, pinned directory descriptors and quarantine identity checks. It never scans directories, deletes original mode, formal assets, history or human edits. Publication/API/search failure prevents cleanup. Archive success with cleanup failure retains records for cleanup-only retry.
