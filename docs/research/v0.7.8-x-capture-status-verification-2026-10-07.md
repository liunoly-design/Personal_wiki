## 实现

- 将目标文章选择集中到 `scripts/x_article.py`，采集和上下文解析共用规则。副本自身正文一致时，仅选择单份已包含全部已见链接、媒体及嵌套引用的候选；引用集合、回复父 ID 或正文存在无法合并的冲突时保持拒绝。
- 修复任务状态中的 HTTP 数字识别：需要明确 HTTP 状态语境，不从任务 ID 或路径的 401/402/403 推断登录或额度。真实 HTTP 拒绝、额度文字、等待和重试预算保持原语义。
- 包版本候选为 0.7.8；此前运行版本仍为 0.7.7。

## 复现与验证

1. 新增队列测试在修复前因 ID 含 401 被误标为 `waiting_login` 而失败；已有私有诊断回放确认 ID 含 402 会误标 `waiting_capacity`。修复后路径数字按原五次预算重试，失败资料保留；真实 HTTP 401/402/403 和 quota 等待在重启后保持。
2. 合成采集测试在修复前拒绝相同正文的裸 URL 补全副本；修复后最终 Markdown 保留链接、图片和原 HTML，重复调用复用缓存，未知串文关系仍显示缺口。
3. 安全回归覆盖真实正文差异、互斥链接/图片、无法同时保留引用与链接、相互冲突的回复父 ID，以及包含全部信息的完整副本在不同排列顺序下稳定被选用。
4. 私有目录对用户已授权来源做默认规则回放：从归档原 HTML 与两张图片产生与此前恢复完全一致的 `article.md`，没有任务专用选择补丁，0 模型调用、0 外部消息。原 HTML 与图片字节一致；未将真实 HTML、附件、来源身份或任务状态提交到仓库。
5. 重新读取同一公开网页，仍无回复父 ID、JSON 回复关系、串文分页或引用。只确认目标文章，不宣称完整串文。新读取仅存于私有诊断目录，未覆盖 Vault 原件或发布新版本。
