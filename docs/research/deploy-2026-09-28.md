## 五项能力

| 功能 | 本次落地 | 边界 |
| --- | --- | --- |
| 名词解释 | Flash 先说明类别、用途、例子与歧义；实体和概念页直接显示“是什么” | 模型说明标记为未经独立核实；文章语境只用于消歧 |
| 全文中文翻译 | 新英文来源生成独立中文阅读稿，使用 Codex CLI `gpt-5.6-terra`；分段保存，失败可继续 | 不回填旧文章；结构校验失败时保留原件并报告待处理 |
| 图片下载 | 可解析的 X、微信正文图片保存到附件包并保留本地引用 | 获取失败如实标为部分完成 |
| 视频下载 | 公开 X 的直接 MP4 下载；优先提取器，失败后对限定主机做有界元数据探测 | 1080p、30 分钟、1 GB 阈值；无法确认则等待。微信嵌入视频、需登录或平台受限视频不保证下载。无转录 |
| Markdown 整理 | 保留标题层次、段落、代码、链接和可对应的视频位置 | 无法对应的附件位置明确标记；不把摘要替代全文 |

入口仍为一条 X 或微信公众号链接：`小婕 wk 记录：链接`。普通博客入口、查询、讨论尚未开放。Agent 工具 `wiki_record`、`wiki_status`、`wiki_retry_translation` 已注册并加入 wiki Agent 权限；工具名不是聊天命令。

新资料通过受保护的本地编译流程归档；已有知识修改进入待审候选，不调用桌面的全量重编译覆盖已有页。
