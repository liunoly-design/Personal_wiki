# Personal Wiki 0.6 讨论与综合 SPEC

日期：2026-10-03；固定基线：56812c8。产品选择与三项任务/测试边界已由用户确认。

## Problem Statement

查询是单轮，讨论入口预留。用户需要围绕已读资料持续追问，明确保存结论，并审阅多来源综合文章。

## Solution

明确讨论入口建立稳定讨论ID；上下文在Vault外恢复。明确保存才生成正式结论，综合草稿走现有待审，批准后可读搜。

## User Stories

1. 用户开始讨论取得D编号并得到基于正文的中文回答。
2. 用户在同一授权会话续聊，或指定D编号恢复旧讨论。
3. 用户新建话题，旧讨论不串入新话题。
4. 用户结束讨论，停止默认续聊，不自动保存到库。
5. 用户指定当前会话已发现K编号及起始行补读正文。
6. 默认只查本库；模型不联网、不切付费服务。
7. 作者观点、模型推断、用户判断分别标注。
8. 原文和译稿按同一来源识别，不能夸大独立证据数量。
9. 不同观点、日期、适用条件与缺口保留。
10. 无证据明确未知，不生成虚构结论。
11. 失败和重启恢复原请求，不把旧消息变成新讨论。
12. 重复消息只产生一次讨论回合、一次保存或一次提案。
13. 跨用户/会话D和K编号不可读取。
14. 长上下文到限额明确停止，保留全部旧内容，不静默丢来源。
15. 明确保存结论生成问题、依据、结论、用户判断、未决问题五部分。
16. 用户判断按原消息记录，模型不能替用户承诺。
17. 保存文章保留实际证据路径、行号、读取时间和内容哈希。
18. 多来源综合生成中文结构草稿，明确冲突与缺口，未批准无正式综合页。
19. 待审沿用R编号、基线、并发保护、历史及核验恢复。
20. 正式保存/批准后有K阅读入口，沿用0.5.2 Markdown分页。
21. 原件、附件、手写内容保持不变。
22. 真实飞书由用户入站验收；自动测试不代发消息、不批准真实建议。

## Implementation Decisions

已确认：每轮在Vault外保存恢复上下文；只有明确保存进入正式库，一次保存一篇；仅本库，允许用户指定已发现来源；综合待审。

工程决定：
- `小婕 wk 讨论：问题` 自动续当前活动讨论，否则新建；`小婕 wk 新讨论：问题` 明确新建；`小婕 wk 讨论：D-编号 问题` 指定恢复；`小婕 wk 结束讨论：D-编号` 结束；`小婕 wk 保存结论：D-编号`；`小婕 wk 综合：D-编号 标题`。
- 问题可附 `来源：K-编号 起始行, K-编号 起始行`（最多5份）和 `用户判断：原话`。来源通过现有已鉴权阅读入口补读；未指定时复用查询候选筛选/正文读取/图谱。续聊以首轮主题与当前问题检索，结合此前已读证据。
- 每轮问题最多2000字；最多20个成功回合，模型上下文总64KiB，证据最多20片段，总64KiB；到限额拒绝并指导保存/新建。完整上下文在外部状态保留，绝不静默滚动丢弃。每片段沿用80行/8000字节，查询总14000字节。
- 先持久化原消息绑定、讨论选择，再调用模型；生成结果持久化后再发布。失败重发相同命令恢复，额度失败不后台无限重试。原消息ID与命令指纹绑定，改变原文拒绝。状态更新串行并有跨进程锁。
- 模型为当前已授权订阅文本Codex；禁用工具、外部访问。事实引用必须落在实际读取片段范围，生成拒答使用固定标记。语义核对仍需人工抽样。
- 正式结论只增发布在wiki/topics，综合正式目标在wiki/synthesis；文件名由程序固定生成，模型不得选路径。结论带明确派生与用户判断标注。来源清单含相对链接、行号及哈希，不复制正文到多个目录。
- 保存先持久化候选再只增发布；原生API回读哈希与搜索发现均通过才完成。失败保留verification_pending，重复命令核验同一内容；不重新生成或覆盖。
- 综合草稿保留在现有wiki/queries待审目录与现有安全元数据中；复用受保护review_store应用，不创建平行待审状态库。生成时记录目标基线；目标默认唯一新页，不重写旧文章。元数据注明所属scope，待审列表/详情/动作重复校验。
- 结论明确保存为正式库知识，可供已授权本库用户查读；未保存讨论仅本用户/会话。正式文章用户判断只按显式用户判断字段逐字记录；问题/模型推断不称为用户判断。

## Testing Decisions

用户已确认公共边界：飞书原消息/用途工具→回执与恢复、受保护发布→文件/API读搜、现有Review→应用/历史。合成样本逐条TDD，不测试私有方法。覆盖隔离、重复、重启、无证据、来源分页、引用错误、限额、模型/API失败、保存与综合、提案注入/旧批准/并发/原件哈希。沿用收集/查询/阅读/待审全回归。真实本库只读模型链路与隔离合成发布验收分开。

## Out of Scope

文件导入、音频、定期Review、备份、GTD、采集重写、付费服务及自动综合批准。0.4.2和0.5真实飞书仍待各自用户验收。
