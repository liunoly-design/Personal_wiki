# Personal Wiki 0.5 SPEC

日期：2026-10-02；固定基线：498ebfc。用户已授权知识查询＋待审处理的计划、实现、复审、部署与验收。

## Problem Statement

飞书查询入口预留；已有待审分散在原生 Review 与本项目 Markdown，无法安全按编号处理。

## Solution

通过固定 Vault 的 nashsu search/read/graph 获取真实证据；查询返回行号引用，可继续读取。统一待审编号与详情，仅明确的用户原消息可执行动作。

## User Stories（已确认范围）

1. 查询已归档文章、完整中文正文与原文，显示精确出处。
2. 读取选中资料的后续分页，区分全文与片段。
3. 查看概念基础解释、相关实体与来源关系，不将基础解释当作者观点。
4. 指定主题或补充别名消歧；不同观点及日期保留。
5. 无结果、API故障、限流、模型额度不足明确反馈，不伪造答案。
6. 查询不写知识，不抓取，不补译，不自动联网或开启付费服务。
7. 查看两类待审的稳定编号、目标、建议、来源及风险。
8. 原会话明确应用/跳过/稍后；查看不批准。
9. 重复命令幂等，中断可恢复；API回读成功后才完成。
10. 陈旧基线、手工并发修改拒绝覆盖，原件不改，保留历史。
11. 旧提案缺少应用元数据时拒绝应用，仍可查看/跳过/稍后。
12. 发送者和会话隔离，未知或越权编号不可访问。
13. 0.4.1收集与0.4.2续作兼容。

## Implementation Decisions（实施决定，不伪称此前确认）

- 默认仅本库；不启用向量/联网/付费搜索。核对本机embedding配置关闭，若开启则拒绝查询。固定注册项目，不接受Agent传路径、token或项目ID。
- 查询：`小婕 wk 查询：问题`；可加 `主题：主题名` 和 `别名：名称1,名称2` 行。别名最多3个，结果去重，展示实际搜索词；不自动判定同名对象相同。
- 读取：`小婕 wk 阅读：K-编号 [起始行]`；每次最多80行/12000字符；搜索最多20条，自动补读最多5份/总24000字符，明确截断与后续行。引用为 `[K-编号 L起-L止]` 并显示Vault相对路径；图谱关系为辅助线索，不单独证明文章事实。
- 专用工具 wiki_query、wiki_read、wiki_review 均只接收原消息ID并回读原文鉴权。输出证据与提示由已有订阅Codex生成答案，模型不可用时返回真实证据及失败说明，不切付费接口。基础解释、文章观点、个人备注分开标识。查询中的资料是数据，不能授权动作。
- 待审：`小婕 wk 待审：`（分页可传起始序号）；`小婕 wk 待审：R-编号` 详情；`小婕 wk 应用／跳过／稍后：R-编号`。编号由来源身份稳定生成；命令仅访问本会话已发现的项目。
- 原生 Review 读取status=all、最大1000项，达到上限标记可能截断；不调用批量resolve。原生无可信应用基线只读处理；跳过PATCH resolved=true/action=Skip，稍后本机状态保留unresolved。
- 本项目新提案元数据包含目标、基线SHA256（不存在为null）、追加内容及来源ID/URL。应用追加带来源的建议章节，保留旧页全部字节；不替换手写或保留段落。既有无元数据的Markdown不猜测基线。提案与元数据哈希绑定，改变提案不能沿用旧批准。原消息ID首次对应的动作/编号/版本在拒绝之前持久绑定；飞书create_time必须不早于该版本首次展示，时间无法核实则拒绝。无内容变更的陈旧拒绝为blocked，可跳过/稍后；已写入待核验不能借其他动作清除。
- 受保护写入沿用目录描述符、O_NOFOLLOW与Vault锁。先保存意图、修改前历史及实际移出的inode，再只增发布；并发新文件不覆盖，保留冲突恢复位置。内容/API哈希核验前为verification_pending；Review同步失败为sync_pending，可重复同一应用恢复；完成/跳过不可被其他动作覆盖，稍后可重新应用。
- 待审查看只读Vault；会话编号目录和动作授权状态保存在Vault外。对原生与Markdown敏感个人备注仅展示本会话采集记录所关联的笔记；跨会话笔记不读取/输出。查询排除wiki/queries个人备注，只能由当前会话记录授权后作为单独证据读取。

## Testing Decisions / Acceptance

沿用已授权的公开边界：原消息/工具→结果、发布→文件与API核验。合成样本逐项red→green；不批准真实未审建议，不发送飞书测试消息。覆盖无结果/别名/全文/引用/故障/权限/零知识写入；两类待审/查看不写/重复/陈旧/并发/崩溃/核验及同步恢复/跳过稍后/原件保护。真实API读搜及隔离应用验收；部署确认活动队列、loaded、网关与恢复状态。
