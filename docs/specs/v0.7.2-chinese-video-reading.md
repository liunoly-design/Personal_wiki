## 交给 Mac mini 服务端 Codex 的要求

既有 v1 API、认证、幂等与 job_id 保持。非中文结果 GET /v1/jobs/{id}/markdown 应包含：

```markdown
## 完整中文译文（本地机器翻译）

[00:00:00.000 → 00:00:05.080] 第一条完整中文译文。

[00:00:05.080 → 00:00:10.520] 第二条完整中文译文。

## 完整原始转写（english）

[00:00:00.000 → 00:00:05.080] First original segment.

[00:00:05.080 → 00:00:10.520] Second original segment.
```

两个章节各出现一次，每条格式为 `[原时间戳] 非空完整正文`。每条中英文时间戳必须完全一致、数量和顺序相同；模型分批翻译可以，交付时必须还原为逐条时间段。manifest.translation.coverage.source_segments 等于原稿和译文的条数；all_source_segments_present 只有逐条核验后才能为 true。transcription.language 仍记录真实原语种，translation.target_language=zh，不伪标原稿为中文。
