# 其他 Mac 安装与每日空闲更新

2026-11-17，用户已确认：每台 Mac 安装 Pwiki 与 LLM Wiki，各用本地 Vault；Mini 仅共用视频下载/转录。每天检查 Pwiki 新发行，空闲时更新，失败保留旧版。

## 交付行为

- 提供 GitHub Release 的统一安装脚本及 Python 管理入口；已有 Homebrew 时自动补齐 Node24、Python3.12、Codex CLI、Chrome 和 Python 捕获依赖。缺少 Homebrew、系统权限或账号时给出明确下一步，不绕过系统授权。
- 一次配置本机独立 Vault、Mini origin 和私有令牌文件，安装薄 skill，以及官方固定版本/哈希的 LLM Wiki。保留已有应用、库、凭据与配置，不复制其他电脑 app-state。
- 只支持已验收的 macOS Apple Silicon；前置检查拒绝其他架构。Mini 服务不被客户端安装修改。
- 每台电脑自行注册当前用户 launchd 更新检查：每小时唤醒，距上次成功检查至少24小时才访问 GitHub；忙碌的已发现更新每小时等待空闲，不运行模型。
- 自动更新仅选定本仓库的稳定 distribution-vX.Y.Z，校验外层 SHA256、发行身份和内部文件，拒绝降级和不兼容 major。下载后执行隔离的中文纯文字转换，核对 Markdown 原文，再在安装器中持互斥锁切换。
- CLI 命令持共享运行锁；常驻 worker 每轮持锁，休眠时释放。安装器持独占锁并再次检查待执行/processing/publishing任务；配置代码自动维护的实例延后，由人工协调，避免两个版本管理器互相覆盖。忙碌不改 current。
- 更新不运行模型、不触碰 Vault、不改私有配置，不自动更新上游 LLM Wiki、不修改全局 skill。skill 保留稳定 CLI 路径，旧技能冲突保留。
- 预检失败不切换；激活后入口检查失败原子恢复旧 current，记录不含原文/凭据的诊断。保留旧版本和恢复日志，支持重启后核对未完成事务。
- CLI、安装器和每日检查的公开命令为验收边界，沿用独立发行规格已确认的安装/转换边界；使用临时 HOME、实际发行 tar 包和 GitHub边界的离线发行样本。验证配置/原件保留、忙碌及并发、哈希篡改、失败保留和安装重放。

## 验收范围

合成测试不冒充另一台真实 Mac 的完整账号登录或实际平台抓取验收。发布后下载校验并在隔离目录安装；不接管本机旧生产 launcher/worker，不在当前聊天另建 Codex 定时任务。新电脑执行统一安装入口后才启用该机系统定时检查。
