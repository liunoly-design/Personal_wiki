用户已明确授权：部署名词解释、全文中文翻译、图片/视频下载、忠实 Markdown 排版，并重新生成当前所有名词，修正实体与概念页缺少“它是什么”的问题。

## 验收范围

- 本机 OpenClaw 切换到已测试的 0.3.0-preview.2，保留其他插件、账号授权及凭据；记录版本和回滚配置。
- 新收集维持单条 X/微信入口；正文、图片、本机可解析的公开 X 视频、完整中文阅读和独立定义进入现有流程。登录/平台不可解析的附件如实报告部分完成；不声称所有站点和受限视频都可下载。
- 视频下载前通过公开 metadata 或限定主机的有界 MP4 探测选择不高于1080p直接MP4，超过30分钟/预计1GB或时长不明时暂停；未知大小达到1GB停止，下载后校验媒体。无播放列表扩展、无视频转录。
- 实体/概念页直接显示类别与通俗定义、例子和歧义；文章中的用途、观点、来源保持独立。
- 现有 glossary 全量重生成；从原始文章片段辨认指代，不把旧解释当事实。现有实体/概念补充独立定义，保留现有正文与引用。
- 私有候选和每批进度保存在 Vault 的 .personal-wiki，应用前保存完整旧页面、比对原哈希；检测到并发变化则保留待处理。
- 保留手写区块和原始资料，不回填既有文章全文翻译。知识定义由模型生成、未经独立核实；不把模型生成当已验证事实。
- 验证代码、图片链接、Markdown结构、原件哈希、名词覆盖数量、插件实际加载及服务可用性。真实飞书入站仍以用户发送消息为准。

## 实施后的保护与恢复

既有页面没有可靠的人工/生成内容归属标记，因此新定义置顶，原有正文完整保留备查；不直接删除旧解释段。实际被移出的文件 inode 保存在 displaced，可恢复旧编辑器句柄产生的晚到写入。原路径仅以排他创建发布，已有竞争者文件不会被替换。

迁移中断时使用 `node scripts/refresh-terms.js /absolute/vault --resume-plan /absolute/plan.json` 重放原计划；不要重新扫描缺页后另建迁移计划。
