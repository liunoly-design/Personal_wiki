# Personal Wiki 0.4.2 SPEC

远端规格：[Issue #19](https://github.com/liunoly-design/Personal_wiki/issues/19)。

日期：2026-10-01；基线：689350a6c3b456cc1a8e6370685e2dd3b236196d。状态：实施规格，交付状态以验收报告为准。

## Problem Statement

复杂 X 的串文和引用上下文可能缺失；登录失败、附件失败及超限视频没有安全的独立恢复入口。正文成功也可能无法阅读，重启可能重新触发等待阶段。

## Solution

保留可追溯帖子与附件，发布已取得正文，显示缺口；用户在原会话按任务与附件编号恢复。成功阶段复用，超限须明确确认，未授权账号不读取。

## User Stories（已确认）

1. 用户收集目标 X 时，保存同作者连续回复链及远端引用，排除其他作者普通评论。
2. 每帖正文、顺序、来源和对应附件可追溯。
3. 分页去重；循环、分页上限及远端缺失明确标记，不能宣称完整。
4. 登录/验证码出现时等待，说明本机操作，无自动登录或验证码绕过。
5. 用户恢复授权会话后继续同一任务，成功抓取、模型与下载不重做。
6. 正文先归档，失败附件逐项补下载；不重复翻译或知识模型。
7. 成功附件和所有历史原件保持字节与哈希。
8. 视频最高1080p，超过1800秒或预计1,000,000,000字节先暂停；未知大小达到阈值暂停。
9. 确认只对应同一任务、附件和元数据指纹；不能借另一个会话授权。
10. 重启保留等待、确认、下载进度及有限尝试次数。
11. 状态与回执显示部分成功、缺口、所需操作和恢复命令。
12. API不可用时不清理；处理中断恢复未完成阶段。

## Implementation Decisions（工程决定）

- 沿用持久采集任务、原生API核验与受保护发布边界。正文/附件/上下文状态独立。
- X 从公开HTML及公开媒体元数据提取；专用隔离 Chromium 会话仅在用户发出“登录继续”后读取当前任务平台。浏览器不复用日常Chrome配置，不导出Cookie；用户先自行登录专用窗口。仅 X/微信来源可使用此会话。
- 从帖子永久链接和明确回复父ID识别连续链；没有父ID时不将同作者任意帖当串文。分页最多20页；远端引用最多20帖、不展开引用的评论。缓存成功页；缺口写正文和结构化清单。
- 飞书命令：`小婕 wk 状态：任务ID`、`小婕 wk 继续：任务ID`、`小婕 wk 登录继续：任务ID`、`小婕 wk 补附件：任务ID 附件ID`、`小婕 wk 确认视频：任务ID 附件ID 指纹`。工具只接收原消息ID，服务端回读原用户消息并核对发送者、会话及完整命令。普通继续不能批准超限或启用登录会话。
- 附件ID/指纹由来源、路径、远端URL、时长、大小和分辨率决定；重启持久保留用户消息ID、发送者、会话、时间。URL或元数据变化旧确认无效。1080p不能被确认豁免；仅确认指定视频的时长/1GB阈值。
- 下载使用验证器及Range继续；服务端无可验证Range时重新下载该失败附件，成功附件不触碰。部分文件存Vault外，不作为正式成功附件。确认前未知大小至1GB停止。
- 正文发布一次；后补附件为只增的附件及补充页，关联原来源，不重写原文/已归档manifest/用户资料卡。状态返回补充页位置。
- 等待登录、确认、输入、媒体、额度等状态重启不自动解除；处理中断保留累计重试预算。网络重试由队列负责，子下载器/HTTP/yt-dlp关闭隐式重试；每个阶段/附件最多五次，用户显式续作开启新的有限周期。
- 不保存私人资料到代码/Issue；网页指令不得控制权限。公网校验和固定已验证IP沿用现有安全HTTP层。

## Testing Decisions / Acceptance

已确认边界：消息/Agent工具 → 任务状态、可见归档、来源及附件哈希；采集CLI → 文件包；发布CLI → 原件保护。用合成HTTP、隔离浏览器及模型/API边界验证，逐项 red→green。

- 串文分页顺序、重复/循环、评论过滤、远端引用及附件归属；缺口显式。
- 401/验证码单次进入等待，重启不重试；授权恢复复用缓存，跨会话拒绝。
- 正文已发布后只补选定附件，成功文件不变、零新增模型调用；API失败保留状态。
- 阈值前/中停止、Range恢复、精确确认、分辨率不豁免；重复命令无副作用。
- 五次总预算及启动恢复；现有博客/文本/多链接/备注/别名/刷新回归。
- 本机部署无活动任务干扰，新不可变release，插件版本、网关、恢复队列、nashsu读搜与原件哈希核验。

## Out of Scope

知识查询/待审应用0.5；讨论、PDF/Office、转录、周期Review、GTD、备份、播放列表；旧归档补译。不能自动批准超限，不能擅自向飞书发送测试消息。
