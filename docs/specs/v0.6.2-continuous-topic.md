# Personal-Wiki 0.6.2：同议题持续记录

基点：3247342 / 0.6.1。2026-10-03。已确认产品规则来自注册目录需求补充及本任务；以下绑定及增量策略为本版工程决定。

## Problem Statement
明确保存的同议题讨论目前每次建页，无法持续记录和稳定引用；新观点必须并列，不能覆盖旧判断。

## Solution
D议题编号持久绑定同一文档，明确保存追加带日期、来源、模型结论及用户原话的条目；明确“新记录”才开启另一篇。普通讨论不写正式知识。

## User Stories
1. 用户明确保存首轮讨论后得到稳定K阅读引用。
2. 用户追加讨论再保存时在同一文档看到新旧观点与来源。
3. 用户重启、重开模型会话后可用同一用户/飞书会话内的D继续；不依靠标题猜测。
4. 用户明确新记录时另建，旧篇保留。
5. 用户重复保存相同回合不重复追加。
6. 用户编辑已有正文后保存新回合，编辑内容保持；真正并发冲突不得覆盖。
7. 保存中断或API未知时重发原命令，先核对持久意图与目标再恢复。
8. 用户原样保存所属议题的被回复消息时追加到议题文档，原JSON与正文只增保留，不调用模型重写。
9. 无可验证议题的原回复继续独立归档，不按标题绑定。
10. 综合文章仍待审，用户判断不由模型生成。
11. 已有0.6.1保存记录通过原请求身份确定最新已核验文档为延续落点，其他旧篇保留；无成功记录则新建。

## Implementation Decisions
- 议题身份为授权用户/飞书会话范围+D；跨模型会话持久恢复，同名新D不自动合并；跨飞书会话不开放隐式绑定。
- 保存结论默认同篇；命令“小婕 wk 新记录：D-编号”另建并成为该D以后保存的当前文档。
- 每次新增结论仅生成自上次成功保存以来的新回合；已有观点不送入替换器。证据可复用已读上下文。
- 保存请求持久冻结内容、时间与回合边界；追加条目具有稳定保存键，用户阅读引用保持稳定。
- 绑定、未完成意图与回合游标使用现有受保护存储及全库锁；追加复用待审的历史/旧inode保护逻辑，不造第二套知识引擎。
- 同议题未核验保存阻止其他新保存先行；读搜核验后再完成并推进游标。真正冲突保留现场供人工核对。
- 模型追问使用最近20回合，完整回合仍持久保留；20片段/64KiB限额继续拒绝超限，保存候选超过64KiB需先分段保存。
- 原回复正文逐字保留，标记模型回复未核验；原件和JSON不覆盖。

## Testing Decisions
沿用已授权的飞书原消息鉴权命令入口、受保护发布接口两条现有公共边界；合成Vault+确定性模型覆盖同篇、重启、稳定引用、显式新篇、重复、跨范围拒绝、Raw字节、API读搜失败恢复、进程中断和并发编辑。真实飞书用户入站/显示与模型语义由用户另验收。

## Out of Scope
0.7安装恢复、录音、跨PGTD接口、自动知识维护、私人账户/代发飞书、自动迁移合并旧篇。

## Further Notes
